# 是时候去看海了 · 私人旅行手账源码

React / Vite / Three.js 可维护源码。交付用途为本地调试和私有仓库保存，不配置网站托管。原 GitHub Pages 旅行子页面已经撤下；旧公共 Git 历史未重写。

## 运行与检查

使用 Node.js 22.12 或更新版本。在本目录运行：

- npm ci
- npm run dev
- npm run check
- npm run build
- npm run preview

开发服务器使用根路径 `/`；构建输出在 dist/client。check 包含数据、DOM 交互、场景与构建检查。安装依赖需访问 npm；之后构建只读取本包的代码、数据、图片和字体，不需要额外研究目录或密钥。本包没有自动推送或部署流程，只应提交到用户确认的私有仓库。

## 已实现交互与验证边界

单指左右滑动旋转立体书，上下滑动保留页面阅读，双指保留浏览器缩放。城市标签也可起手旋转，拖动后不会误选；轻点、键盘、鼠标、旋转与重置按钮保留。事件测试覆盖取消、双指切换、重复操作及鼠标流程，但没有物理 iPhone 触摸、GPU 或性能通过结论。WebGL 不可用时仍可使用二维路线和全部旅行资料。

5 / 6 天选择、日期、小车与城市联动；自选和印章只存于当前浏览器。清理浏览器数据会清除记录，暂不跨设备同步。全部行驶时长和费用是规划假设，新增绕路时间需实时导航核算；不会为了添加景点压缩驾驶休息与返程缓冲。

36 张景点卡中，2 处有小红书私人参考图片（民主路、盐河巷），34 处尚缺小红书图片；另保留 20 处各一张其他来源许可实景图，不冒充小红书图片。18 处有景点或餐区专门帖子。精选 12 处中，7 处有许可照片，2 处有私人参考照片，3 处暂无站内照片。候选卡不代表全部进入主行程，占位图标与程序生成的 3D 模型不是现场照片。

小红书两张首图保持原文件和水印，作者分别为巧克力爱好者（民主路）、行走的摄影师（盐河巷）。图片为私人旅行参考，未取得公开转载许可，不能上传公开仓库或公开部署。完整署名和无参数原帖链接见 public/data/attraction-media.json 的 private_reference_images。PRIVATE-REFERENCE-FILES.json 与许可图片清单 MEDIA-PUBLISH-FILES.json 分开保留。

小红书正文仅保留短原创摘要，链接均为无分享参数的文章入口，可能需要 App、登录或按标题与作者搜索。正文已读不等于当前链接可达，也不代表原图、全部评论和手机表现已核验。原始外部图片有自己的权利限制，本包不授予新的公共使用许可。

## 文件与维护

- src：页面、交互与程序生成的三维模型
- public/data：带来源的路线、景点、图像归属、原帖摘要
- public/assets：本地图片、字体及许可证
- tests：数据、UI 和场景回归测试
- scripts/verify-assets.mjs：图片、作者、来源、许可分类与文件清单一致性
- package-lock.json：保留实际依赖版本和完整性锁定

更新数据须保留来源、时间与核验边界。新增图片时同步对应清单和权利类别，不把私人参考图标为可公开转载。票务、营业、停车、天气、导航和住宿库存必须以出行时信息为准；本项目未预订住宿或门票。
