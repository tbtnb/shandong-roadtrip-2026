# 是时候去看海了 · 旅行手账

基于用户提供的 `shandong-roadtrip-2026-source.zip` 继续维护的 React / Vite / Three.js 源码。公开源码仓库为 https://github.com/tbtnb/shandong-roadtrip-2026。用户于2026-10-01确认全部公开，在同仓库使用gh-pages成品分支部署Pages。

## 使用

Node.js 22.12 及以上，在项目目录运行：

```sh
npm ci
npm run dev -- --host 127.0.0.1 --port 5188
```

打开 http://127.0.0.1:5188/。构建运行 `npm run build`，完整代码检查运行 `npm run check`。安装依赖需访问 npm；构建读取包内源码、数据、原图和字体，不依赖登录凭据或研究工作目录。

## 两种阅读方式

默认是**沉浸体验**：先选择 5 / 6 天、俯瞰全程，点击“开始旅程”后镜头平滑降到纸页上的低位第一视角。接着按“当天路书 → 景点与自选 → 这一站吃什么 → 下一天”浏览；也可直接点当天的三个步骤。最后完成的是行程预览，不代表真实到访。

顶部的**攻略模式**展开完整路书、景点、城市指南、准备事项和来源资料。切换阅读模式保留天数、日期和预览进度；景点自选与印章共用同一份浏览器记录。日期集中在工作区顶部；地图选城同步到对应日期。相机的“俯瞰全图 / 第一视角”仅调整视角，返回全程预览另有明确入口。资料菜单打开独立照片、美食、准备或来源视图，返回保留当前日期和步骤。

单指横向拖动旋转或环顾，纵向滑动滚动页面；双指保留浏览器缩放。触摸取消、多指切换、城市标签起手、拖动后误点击、鼠标及笔操作有回归覆盖。旋转、重置、暂停、2D / 3D 切换、日期、城市和印章功能保留。WebGL 不可用时仍能完成二维引导和阅读资料。

自选、分钟及印章保存于当前浏览器，5 / 6 天的自选分别存储。清理浏览器数据会清除这些记录，暂不跨设备同步。新增绕路时间、酒店库存及实时导航未核算，路线卡保留驾驶休息与返程缓冲。

## 36 处原图与原帖

36 / 36 处均有至少一张地点匹配的小红书原始 JPEG，作者和图片对应的单篇原帖入口直接显示在卡片上。民主路、盐河巷使用 ZIP 中已有的两张原图，并重新打开原帖核对；另外 34 张通过本机浏览器的网站正常下载功能取得。餐饮街区使用该街区的具体实吃帖子。部分原文件为实景照片拼图，保留其原始文字、水印和完整像素；没有用视频转帧、图库或 AI 图替代小红书照片。

逐点标题、作者、原图、文件 SHA256、识别依据及实测日期见 [36处来源清单](research/place-sources.md) 和 [机器可读清单](research/place-sources.json)。图片权利清单是 `PRIVATE-REFERENCE-FILES.json`，采集时均标记为私人参考用途；公开展示现已由用户确认，原作者再使用许可仍未建立；另保留的 20 张其他来源许可照片由 `MEDIA-PUBLISH-FILES.json` 管理，未计作小红书原图。

采集者实际从站内搜索打开并阅读每篇对应帖子，并另行打开卡片采用的无参数链接。**本次 36 个无参数入口均返回无法浏览 / 404 / App 提示**，页面如实标注并提供标题和作者供站内搜索。搜索入口能读与无参数入口失败分别记录；没有保留签名链接、Cookie 或访问令牌。未验证匿名、App 内或真实 iPhone 打开。原帖正文只保留短摘要，原作者保留照片权利，用户于2026-10-01明确确认改为在GitHub Pages公开展示，保留作者和水印；这项确认不等于原作者授予公开再使用许可。

## 城市图库与美食库

无需开始旅程，在页顶“资料 → 城市实拍”即可打开全部36处，按城市筛选，包括淮安途中备选。地点照片仍保留原作者与单篇原帖入口。

“资料 → 美食图文”或当天第三步按城市、小吃 / 正餐 / 甜品和推荐等级筛选。每个店铺记录独立小红书正文、评论、作者背景、原图、点评与地图实测状态；“暂不推荐”默认隐藏，可以单独查看。其余五城目标为青岛60、威海80、连云港40、日照40、淮安20，共240家，目标并非已完成数量。用户已明确芜湖仅半天出发中转，暂停补采，已有7家图文保留作出发早餐参考，不计目标。最新实收数量以页面和 [美食采集账本](research/food-source-ledger.md) 为准。其余五城各由一位调研负责人持续整理，芜湖负责人已停止。

美食原图位于 `public/assets/food/`，允许原始 JPEG / WebP / PNG，保持原文件哈希、尺寸、作者与水印；没有统一转换或裁切。采集记录齐全仅表示原帖实读、原图和平台链接状态齐全，不能替代营业与口碑核实。分店不一致、搜索备选、需要App或无法打开均保留实际边界。帖子中的个人投诉不作为已证实事实。

维护时 `npm run import:food -- /绝对路径/food-research` 导入五位在采城市负责人及已暂停芜湖负责人的已完成记录；不完整记录留在研究目录。导入器先校验原图、单帖身份和链接参数，再更新数据和私有文件清单。构建不依赖该研究目录。已打开页面每分钟检查美食资料更新，保留当前旅程和筛选。

## 验证证据与边界

`npm run check` 包含内容数据、模拟 DOM 交互、场景 CPU 回归、图片一致性检查和生产构建。原生 Chrome 浏览器另验证真实 WebGL 画面、可信触摸输入、纵向滚动、镜头切换和引导流程。约 1.1 秒的入书动画记录了 68 个中间帧，并覆盖选城、重置、返回全图的中断。

浏览器触摸输入模拟不等于真实 iPhone；本次没有物理 iPhone / Safari、硬件双指缩放或手机性能通过结论。普通窄屏截图仅用于布局检查。详细证据见 `research/testing/`，照片独立本地审核与连云港原帖复核见 `research/final-audit`、`research/lyg-recheck`。

## 维护与归属

- `src/`：页面、引导流程、交互与程序生成的立体书。
- `public/data/`：路线、景点、来源摘要与原图对应关系。
- `public/assets/`：原始照片、许可照片、字体及许可证。
- `scripts/verify-assets.mjs`：图片类型、哈希、作者、来源与文件清单一致性。
- `scripts/generate-source-ledger.py`：生成实际展示照片与原帖的逐点清单。
- `tests/`：数据、UI 和场景回归。

`ATTRIBUTIONS.md` 保留许可图片署名；`THIRD_PARTY_NOTICES.md` 保留软件许可证；Ma Shan Zheng 字体的 SIL Open Font License 在 `public/assets/fonts/OFL.txt`。票务、营业、停车、天气和导航需要出行时重新核对，本项目未代订住宿或门票。

## GitHub Pages 部署

网站地址：https://tbtnb.github.io/shandong-roadtrip-2026/ 。源码仓库已按用户要求设为公开；`main` 保存源码，`gh-pages` 保存构建成品，Pages自动发布成品分支。

`npm run build:pages` 构建并校验 Pages 子路径、字体、数据及原图哈希。修改源码后先提交，再运行 `npm run deploy:pages`，通过本机现有 Git 凭据把成品推送到同仓库 `gh-pages`，GitHub 随后部署。`deployment.json` 显示对应源码版本。需要 Node.js 22.12+、Git 和仓库写入权限；没有新增凭据或在源码内保存访问令牌。当前 OAuth 凭据没有自定义 workflow 写入权限，因此没有提交自定义 Actions 工作流。

网站公开可访问，用户已明确确认原图公开展示并保留作者、水印及单帖入口。此确认不等于原作者授予图片许可，历史权利字段不改写为已获许可。美食收集仍持续进行，当前上线的是已审核快照；后续采集经导入并重新部署后才更新线上。
