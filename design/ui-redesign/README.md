# Hand-drawn travel journal UI

Current requested direction: natural paper, watercolor blue, fine ink rules, handwritten headings, restrained photo mounts. Body copy remains readable system sans.

The five `handdrawn-*.png` mockups were successfully generated with the built-in image_gen tool, saved and inspected before hand-drawn implementation. Prompts are in `handdrawn-prompts.json`.

The earlier `01-*` through `05-*` editorial mockups are **superseded / rejected** after the user requested hand-drawn style. They are retained only as design history and are not the implementation reference.

Actual page photographs come from the existing source data. Mockup photographs are conceptual and are not used on the site. The map remains actual interactive Three.js models, not a generated mockup bitmap.

Built-in image_gen also produced the natural paper background and transparent watercolor brush materials in `public/assets/journal/`. Their prompts are in `materials-prompts.json`.
