# 卡片集合 · 方案 C

用户于 2026-10-01 从三版中选择「趣味插画卡牌」。`selected-C.png` 是选定的视觉参考；`ui-concept.png` 是此前被放弃的初稿。设计稿中的照片、计数与菜品是示例，不进入业务数据。

实现使用现有 36 个景点与 103 家美食，按芜湖、连云港、青岛、威海、日照、淮安分包。所有真实照片继续保留完整画面、作者与来源。新海岸装饰来自 GPT Image 2，位于 `public/assets/collections/coast-banner.png`，仅作装饰，不充作实景。

功能：喜欢、跳过、撤销、按类型与选择状态重看、详情对话框、收藏列表、选择持久化、按城市串联路线和美食、PNG 长图导出。路线是收藏城市的去程/返程示意，不提供道路导航或最短路径保证；淮安只有主动收藏时才出现。待核与排除提示随收藏保留。

导出在浏览器内完成，使用原始照片和来源文字；以完整卡片为单位分段，每张图不超过 10000 像素高度。常规少量收藏导出单张长图，全部 139 张的布局测试验证不丢卡。照片载入失败时明确显示占位说明。

验证：34 项原有及新增 UI 检查通过后，另新增滑动方向/取消回归；真实浏览器验证点击、撤销、详情、横向拖动、刷新恢复、390px 无横向溢出与 PNG 下载。尚未在实体手机上验证。
